What you can do

The same tools your office already uses, on screen.

Shuleka follows the daily work of a school clerk and teacher: load a class, find a student, enter marks, print a report. Parent messaging, attendance, and more are coming next.

Students

Load a class list, search by name or admission number, add one student or import from Excel, and move learners between streams.

Schools, grades & streams

Keep each school’s structure in one place so class lists, marks and reports stay attached to the right stream.

Teachers

Hold staff records and control who can sign in, so teachers only see the classes they should.

CBE assessment

Set up exams, enter marks, and keep competency-based records ready for reporting.

Marks entry

Enter scores from a computer or phone. The layout matches a mark sheet, not a long form.

Report cards

Generate class reports and learner report cards from the marks you already entered.
